# "종료가치가 80~90%"는 상수가 아니라 n의 함수다

칼럼의 "근미래 파트는 전체의 10~20%" (raw line 265)는 **n = 3~5를 전제로 한 수치**인데, `reference/dcf-core.html` §2가 이를 조건 없는 법칙처럼 적어 두고 있었다. 같은 문서가 동시에 "n을 10까지 늘려 수렴 경로를 그린다"고도 말하고 있어 서로 충돌했다. 예시 모델(r 9.1%, g 3.75%, 3년 12% 성장 후 선형 수렴)로 검산한 결과 종료가치 비중은 n=3에서 86.9%, n=5에서 79.5%, n=10에서 64.4%로 크게 움직이고, **총 가치도 2,156 → 2,682로 함께 커진다**. 레퍼런스 §2를 수정했고, 이 n-의존성을 L0002의 중심 beat로 삼았다.

**Implications**

- n은 "몇 년까지 볼까"라는 기술적 설정이 아니라 **"이 지수가 언제 평범해지는가"에 대한 뷰**다. L0006(시나리오 설계)에서 시나리오별 수렴 속도를 다룰 때 이 프레임을 재사용할 것.
- L0007(민감도)에서 "입력값 1% 변화 → 몇 포인트"를 계산할 때, **n을 고정하지 않은 민감도는 의미가 없다**. 민감도 표에는 항상 n을 명시할 것.
- 다모다란의 반대 방향 경고(TV가 지배한다 → 근미래를 더 조여야 한다, `Myth 5.5`)를 함께 가르쳤다. "종료가치가 87%니 EPS는 대충"이라는 오해가 생기면 이 레코드를 참조.
- 검산 스크립트는 `assets/dcf.js`의 `twoPart` / `convergePath` 프리미티브로 돌렸다. 이것은 **교과서 구조 모델이지 Valley AI 재현이 아니다** — 칼럼의 9,513 / 6,710 / 5,407 역검증은 여전히 미결.
