# Notes

## 사용자 선호
- **언어**: 한국어 본문 + 전문용어 영어 병기. 예: `영구성장률(terminal growth, g)`
- 강의(월가아재 글로벌 매크로 지식편)와 어휘를 맞출 것. 원문에서 쓰는 표기를 우선한다: 주주환원율, 유보율, 기간 프리미엄, 중립 실질금리, 내재 위험 프리미엄.

## 사전지식 기준선 (2026-08-01 확인)
| 영역 | 상태 |
|---|---|
| 경제지표·사이클 (Week 1~8) | 노출됨, 재설명 불필요 |
| DCF | **처음** |
| 재무제표·회계 (EPS, ROE, 자기자본, 자사주 소각) | 약함 |
| 금리·채권 (10년물, TIPS, 기간 프리미엄, 실질금리) | 약함 |

→ 레슨 순서를 짤 때 회계·채권 개념은 "그 레슨에 필요한 만큼만" 끼워 넣는다. 별도의 회계 레슨을 앞세우지 않는다 (미션에서 멀어짐).

## 티칭 방침
- 한 레슨 = 하나의 win. 이 칼럼에는 최소 10개 단위가 들어 있으므로 절대 한 번에 다루지 않는다.
- 칼럼의 숫자(S&P 7,411 / AAA 5.86% / 버핏지수 234.3% / EPS 컨센서스)는 **2026년 7월 시점 월가아재 본인의 값**이다. 워크드 예제로 가르치고, 숙제 실행 시점에만 최신값을 새로 뽑는다.
- 시나리오 확률 35 / 15 / 50 은 월가아재의 **주관적 사전확률**이다. 방법론이 아니라 그의 뷰. 반드시 그렇게 구분해서 가르칠 것 — Index DCF의 요점은 *사용자 본인의* 뷰가 들어가는 것.
- 퀴즈 보기는 **글자 수를 정확히 맞춘다** (공백 포함). 길이 차이가 정답을 흘린다.

## 레슨 로드맵 (잠정)
1. ✅ 0001 — 할인율: 왜 미래 돈을 깎는가, r = 무위험 + 리스크 프리미엄
2. 0002 — 2단 구조: 근미래 파트 vs 종료가치 파트, 그리고 종료가치가 전체의 80~90%를 지배한다는 사실
3. 0003 — g = ROE × 유보율, 그리고 주주환원율 = 1 − g/ROE (종료가치 입력값이 서로 묶여 있다는 것)
4. 0004 — 장기 무위험수익률 3분해: 중립 실질금리 + 기대 인플레 + 기간 프리미엄 (TIPS 브레이크이븐, CPI/PCE 일관성)
5. 0005 — ERP: 과거 데이터 방식의 문제 → 내재 ERP → 순환논리 → 레짐으로 푸는 법
6. 0006 — 시나리오 3종 설계와 내부 일관성 점검
7. 0007 — 민감도 분석: 입력값 1% 변화 → 적정가치 몇 포인트
8. 0008 — 숙제 리포트 작성 (실전 실행)
