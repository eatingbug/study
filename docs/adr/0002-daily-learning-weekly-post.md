# 매일의 학습과 글쓰기를 주간 포스트로 연결한다

2026-10-26, 사용자는 하루 기본 30분 동안 최소 레슨 한 개 학습과 자기 문단 한 개 쓰기를 수행하고,
이를 매주 eatingbug.github.io의 포스트로 발전시키기로 했다.
새 레슨 수보다 산출물 완료를 우선하므로 미결 레슨의 복습·요약·적용도 하루 학습으로 인정한다.
개념을 처음 배우는 동료 개발자를 독자로 삼고, 실험 결과가 부족한 주에는 검증 범위를 밝힌
개념·예시 설명 글을 발행한다. 이는 실험 성과를 기다리며 발행을 미루는 대신 매주 설명하는 습관을 택한 결정이다.

일일 문단 원본은 기존 블로그의 주간 GitHub 이슈 댓글에 유지하고 study에는 링크와 학습·적용 기록을 둔다.
모바일 쓰기 루틴을 유지하면서 원문을 중복 관리하지 않기 위해서다.
AI는 질문·구조 피드백·기계적 교정·Jekyll 형식 준비만 돕고, 초고·윤문·예시문은 사용자가 쓴다.
일요일 21시 실제 발행은 사용자가 맡는다. 이번 변경은 study 저장소에 한정한다.
