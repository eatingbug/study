Reference 0000 · 상시 참조

용어집

레슨에서 모르는 말이 나오면 여기를 봅니다. 한 용어는 한 뜻으로만 씁니다. 다른 말로 바꿔 부르지 않습니다.

§1 · 기계를 다루는 말

용어뜻왜 중요한가
LLM
대규모 언어 모델		 글을 읽고 글을 쓰는 프로그램입니다. ChatGPT와 Claude가 여기 속합니다. 우리가 만드는 제품의 부품입니다.
프롬프트
prompt		 LLM에게 주는 지시문입니다. 프롬프트를 바꾸면 결과가 바뀝니다. 그래서 버전을 관리해야 합니다.
토큰
token		 LLM이 글을 세는 단위입니다. 한글은 대략 한 글자가 한 토큰입니다. 요금이 토큰 수로 매겨집니다. 비용 계산의 기본 단위입니다.
RAG
검색 증강 생성		 질문에 답하기 전에 먼저 자료를 찾아서 LLM에게 같이 넘기는 방식입니다. 틀린 답이 나오면 원인이 둘입니다. 자료를 못 찾았거나, 찾았는데 잘못 읽었거나.
에이전트
agent		 LLM이 스스로 도구를 골라 쓰면서 여러 단계를 밟는 방식입니다. 도구를 쓰므로 실제로 무언가를 바꿉니다. 그래서 안전이 문제가 됩니다.
프롬프트 인젝션
prompt injection		 공격자가 데이터 안에 지시문을 숨겨 넣는 공격입니다. LLM이 그것을 지시로 읽습니다. 메일을 읽는 에이전트는 메일 본문의 지시를 따라 버릴 수 있습니다.
파인튜닝
fine-tuning		 우리 데이터로 모델 자체를 더 학습시키는 것입니다. 비싸고 되돌리기 어렵습니다. 면접에서는 안 하는 이유를 말할 수 있는지를 봅니다.
레이턴시
latency		 요청을 보내고 답을 받기까지 걸리는 시간입니다. 사용자가 기다립니다. 품질과 맞바꿔야 하는 경우가 많습니다.
배칭
batching		 여러 요청을 묶어서 한 번에 처리하는 것입니다. 묶으면 처리량이 오르고 대기 시간도 같이 오릅니다.

§2 · 품질을 다루는 말

용어뜻왜 중요한가
자동채점
AES		 사람 대신 프로그램이 답안에 점수를 매기는 것입니다. 사용자가 현업에서 운영하는 제품이 이것입니다. 영어 작문을 채점합니다.
루브릭
rubric		 채점 기준표입니다. 항목별로 몇 점을 주는지 글로 적어 놓은 것입니다. 기준이 글로 있어야 사람과 기계가 같은 잣대를 씁니다.
밴드
band		 점수 구간입니다. 예를 들어 1점부터 5점까지 다섯 칸입니다. 점수가 연속이 아니라 칸이므로, 한 칸 차이와 세 칸 차이는 뜻이 다릅니다.
평가
eval		 시스템이 얼마나 잘하는지 숫자로 재는 일입니다. 재지 않으면 좋아졌는지 나빠졌는지 알 수 없습니다.
평가셋
eval set		 평가에 쓰는 고정된 문제 묶음입니다. 같은 문제로 재야 지난번과 비교할 수 있습니다.
judge
LLM-as-judge		 LLM이 다른 출력을 평가하게 만드는 방식입니다. 이 워크스페이스에서는 두 개를 구분합니다. 아래를 보세요.
Judge A 사용자의 제품입니다. 답안에 루브릭 밴드 점수를 줍니다. 출력이 등수처럼 순서가 있습니다. 정답은 사람 채점자의 점수입니다.
Judge B Judge A를 평가하는 장치입니다. "이 채점이 실패했는가"를 예/아니오로 답합니다. "판정은 예/아니오로 하라"는 원칙은 B에만 적용됩니다. A에 적용하면 제품이 깨집니다.
정답 라벨
ground truth		 사람이 직접 매긴 정답입니다. 사용자에게는 이것이 없습니다. 그래서 정답과 비교하는 지표를 지금은 못 씁니다.
보정셋
calibration set		 사람이 정답을 매겨 놓은 표본 묶음입니다. 보통 100건에서 300건입니다. 이것을 만들면 "틀렸는지 알아챌 수" 있게 됩니다. 없던 검증력이 생깁니다.
회귀 테스트
regression test		 바꾸기 전과 바꾼 후를 같은 문제로 비교하는 검사입니다. 프롬프트를 고쳤을 때 다른 데가 망가졌는지 자동으로 잡아냅니다.

§3 · 배우는 일을 다루는 말

용어뜻왜 중요한가
performance
수행		 지금 이 순간 관찰되는 성적입니다. 지금 잘한다고 해서 나중에도 잘하는 것은 아닙니다.
learning
학습		 시간이 지나도 남는 변화입니다. 한참 뒤에 다시 재야 보입니다. 면접은 6개월 뒤입니다. 우리가 원하는 것은 이쪽입니다.
저장 강도
storage strength		 얼마나 깊이 학습되었는지를 나타냅니다. 한번 쌓이면 사라지지 않습니다. learning이 재는 것이 이것입니다.
인출 강도
retrieval strength		 지금 이 순간 얼마나 쉽게 떠오르는지를 나타냅니다. 시간이 지나면 줄어듭니다. performance가 재는 것이 이것입니다. 높다고 좋은 것이 아닙니다.
간격
spacing		 한 번 공부하고 다시 볼 때까지 비워 두는 시간입니다. 간격을 두면 같은 공부량으로 더 많이 남습니다.
교차
interleaving		 한 주제로 돌아오기 전에 다른 주제를 끼워 넣는 것입니다. 따로 쉬는 시간을 만들지 않고도 간격이 생깁니다.
바람직한 어려움
desirable difficulty		 공부하는 동안은 성적을 떨어뜨리지만, 나중에 더 많이 남기는 조건입니다. 간격과 교차와 인출이 여기 속합니다. 하는 동안 기분이 나쁩니다.
RI
retention interval		 마지막으로 공부한 날부터 시험 보는 날까지의 기간입니다. 최적 간격이 이 값에 따라 달라집니다.
