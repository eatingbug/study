Reference 0003 · 운영 경험 기록

운영 경험 기록 양식

비교 기준과 검증 범위가 있는 경험 한 건을 남길 때 사용합니다.

비교 기준(baseline)은 변화의 크기를 판단할 때 기준으로 삼는 측정값과 조건입니다.

다섯 줄 양식

  1. 문제: 사용자에게 생긴 영향 / 내가 맡은 범위
  2. 선택: 바꾼 것 / 검토한 대안 / 선택한 이유
  3. 비교: 전후 값 / 단위 / 기간 / 입력 조건 / 포함한 비용
  4. 검증: 품질 기준 / 표본 수와 구성 / 허용 범위 / 결과
  5. 한계: 확인하지 못한 조건 / 다음 확인 방법

기록할 때 확인하기

  • 직접 측정한 값, 추정한 값, 기억나지 않는 값을 구분합니다.
  • 변경 전후에 처리량·입력 길이·재시도·요금 조건이 달랐는지 확인합니다.
  • 팀의 결과와 내가 맡은 판단·구현을 나눠 적습니다.
  • 품질 평가를 하지 않았다면 품질을 유지했다고 쓰지 않습니다.
  • 허용된 집계 숫자만 남깁니다. 사내 로그와 원자료는 저장소에 넣지 않습니다.

다음에 다시 쓰기

업무에서 변경을 마친 날에 다섯 줄을 작성합니다. 다음 복습에서는 기록을 덮고 선택의 이유부터 설명합니다.

이 양식과 반복 방법은 저자의 제안입니다. Google의 장애 회고 지침을 개인의 운영 경험 기록에 응용했습니다.

근거: Google SRE Workbook, Postmortem Culture. 수치, 경과, 후속 조치를 남기는 부분을 참고했습니다.
